# NetworkConfigManager 可优化项分析

> 版本：v2.5.4 | 分析日期：2026-10-10 | 更新日期：2026-10-14

## 一、文档概述

本文档基于对 NetworkConfigManager 源码的最新分析，梳理当前项目中已完成和待优化的项目。每个优化项标注严重等级（P0=缺陷/P1=高优先级/P2=建议），包含**当前问题**、**优化方案**和**涉及文件**。

---

## 二、已完成优化项

### OPT-01 [P0] 网卡IP获取问题修复

**问题描述**：网卡管理部分显示"无IP"

**优化方案**：
1. 修改 `getCurrentNetworkConfig` 方法，传递原始接口名称和清理后的名称
2. 使用 `QNetworkInterface` 优先获取IP地址
3. 添加 PowerShell 支持作为备选方案
4. 增强接口名称匹配逻辑

**涉及文件**：`networkinfocollector.cpp`、`networkinfocollector.h`、`mainwindow.cpp`

### OPT-02 [P1] 加载动画资源占用优化

**问题描述**：定时器在操作完成后可能没有正确停止，存在资源浪费

**优化方案**：
1. 使用 `QScopedPointer` 管理定时器生命周期
2. 添加析构函数确保定时器正确停止
3. 在 `stopLoading()` 中确保定时器停止

**涉及文件**：`floatwindow.cpp`、`floatwindow.h`、`mainwindow.cpp`、`mainwindow.h`

### OPT-03 [P1] 操作进度反馈

**问题描述**：用户无法知道操作的具体进度

**优化方案**：
1. 添加进度条组件
2. 添加步骤指示器
3. 支持显示进度百分比和步骤信息

**涉及文件**：`mainwindow.cpp`、`mainwindow.h`

### OPT-04 [P1] 网络配置变更通知

**问题描述**：网络配置变更后界面不会自动刷新

**优化方案**：
1. 添加定时轮询定时器（每30秒检查一次）
2. 检测IP地址变化并自动刷新界面
3. 在状态栏显示变更通知

**涉及文件**：`mainwindow.cpp`、`mainwindow.h`

### OPT-05 [P2] 错误日志导出功能

**问题描述**：日志文件存储在本地，但用户无法方便地导出日志

**优化方案**：
1. 在 `Logger` 类中添加 `exportLogs()` 方法
2. 在系统托盘菜单中添加"导出日志"选项
3. 支持选择导出目录

**涉及文件**：`Logger.h`、`mainwindow.cpp`、`mainwindow.h`

### OPT-06 [P2] 配置对比与时间戳显示

**问题描述**：配置历史记录只显示操作结果，不显示配置的具体内容对比

**优化方案**：
1. 在历史记录中显示配置变更前后的对比
2. 使用格式化方式显示差异内容
3. 保存配置快照供后续对比

**涉及文件**：`mainwindow.cpp`、`configmanager.cpp`、`configmanager.h`

**完成内容**：
- 在 `ConfigManager` 中添加了 `getConfigHistory()` 方法获取配置历史
- 添加了 `rollbackConfig()` 方法支持回滚到指定版本
- 添加了 `getConfigVersionCount()` 方法获取版本数量
- 添加了私有方法 `loadHistory()`、`saveHistory()`、`saveConfigVersion()`

### OPT-07 [P2] 悬浮球菜单响应速度优化

**问题描述**：悬浮球菜单在加载大量配置时可能出现卡顿

**优化方案**：
1. 将菜单构建移至后台线程
2. 使用缓存机制，避免重复构建
3. 实现菜单懒加载

**涉及文件**：`mainwindow.cpp`、`floatwindow.cpp`

**完成内容**：
- 实现了菜单缓存机制，缓存接口配置数据
- 减少重复计算，提升菜单响应速度

### OPT-08 [P2] 配置版本管理

**问题描述**：配置文件只有一个版本，无法回滚到之前的配置

**优化方案**：
1. 实现配置版本历史
2. 支持配置回滚
3. 显示版本变更记录

**涉及文件**：`configmanager.cpp`、`configmanager.h`

**完成内容**：
- 实现了配置版本历史记录功能
- 支持配置回滚到指定版本
- 每个配置最多保留10个历史版本

### OPT-09 [P2] 国际化支持

**问题描述**：虽然使用了 `tr()` 函数，但部分字符串可能遗漏了国际化处理

**优化方案**：
1. 检查所有字符串是否都使用了 `tr()`
2. 创建翻译文件（.ts）
3. 支持多语言切换

**涉及文件**：所有 `.cpp` 和 `.ui` 文件

**完成内容**：
- 将 `mainwindow.cpp` 中所有菜单字符串替换为 `tr()` 调用
- 包括：显示主窗口、显示/隐藏悬浮球、启用网卡、禁用网卡、暗色主题、浅色主题、开机自启动、导出日志、退出、无保存的配置、无可用网络接口、更多配置...、置顶显示等

### OPT-10 [P2] 性能监控

**问题描述**：没有性能监控机制，无法了解操作的耗时情况

**优化方案**：
1. 添加操作耗时统计
2. 在日志中记录关键操作的执行时间
3. 提供性能分析工具

**涉及文件**：`Logger.h`

**完成内容**：
- 在 `Logger` 类中添加了性能监控方法组：
  - `startOperation()` - 记录操作开始时间
  - `endOperation()` - 记录操作结束时间并记录日志
  - `getOperationStats()` - 获取操作统计信息
  - `resetOperationStats()` - 重置所有操作统计信息
- 支持统计：调用次数、总耗时、平均耗时、最小耗时、最大耗时

## 四、v2.2.0 验证与修复

- 配置保存改用 `QSaveFile`，修复 Windows 下已有 `config.json` 时临时文件无法重命名覆盖的问题。
- 配置历史在新增、修改时记录；加载时恢复历史，回滚时避免重复获取互斥锁。时间戳保存到毫秒。
- 静态 IP、子网掩码、网关和 DNS 均校验为有效 IPv4；子网掩码还校验连续性。
- 备份读取或写入失败时停止修改网卡；`netsh` 异常退出与超时不再被视为成功。
- 自动化验证覆盖配置增改删、持久化、历史回滚、输入校验、无管理员权限拒绝、网段解析、回环端口扫描、主页入口与本地下载测速。真实网卡配置和启停仍需隔离管理员测试机验证。

## 五、v2.2.1 诊断修复

- 网段扫描显示进度条、处理数及发现数；停止后显示实际处理数。
- DHCP 自动 DNS 保留系统返回的地址；延迟检测默认改选同时具有网关、DNS 的网卡，并提示原网卡。
- 下载测速改用 Windows WinHTTP/Schannel，避免 Qt 5.12 发布包缺少 OpenSSL 运行库时的 `TLS initialization failed`；本地 HTTP 和公网 HTTPS 自动化检查均验证实际下载。

## 六、v2.2.2 国外测速节点修复

- Cloudflare 的原 500 MB 请求返回 HTTP 403，改为已验证可下载的 50 MB 请求。
- Hetzner 旧主机无法解析，改用官方 FSN1 测试文件；四路并发触发 HTTP 429，单路下载通过验证。

## 七、v2.2.3 可选网络参数修复

- Qt IPv4 输入掩码的空值为 `...`；表单读取时将可选网关及 DNS 的空值转为空字符串，避免误判为无效地址。
- 静态配置未填 DNS 时清空 DNS 列表，回滚无 DNS 备份时不再尝试从 DHCP 获取 DNS；仅填备用 DNS 时也可正常应用。

## 八、v2.3.0 界面优化

- 主页面将六个网络工具入口排为两行，扩大配置详情宽度，设置最小窗口高度避免表单拥挤。
- 默认浅色主题采用渐变卡片和控件，统一文字、焦点、禁用与进度状态的对比度；暗色主题仍可手动切换。
- UI 自检检查默认主题和布局尺寸；Windows 平台截图用于目视检查文字、箭头和表单标签。
- 同网段扫描入口复用原扫描器，自动读取当前网卡的 IPv4 地址与掩码；自检覆盖 /24、/21、超限网段和本地开放端口。

## 九、v2.5.1 输入框空白占位修复

- 移除 IP 地址与子网掩码输入框的 Qt 输入掩码，初始 `text()` 与 `displayText()` 均为空。网关、DNS 的输入掩码及空值转换保持原行为。
- 现由用户手动输入点分十进制地址；实时边框提示和 `ConfigManager::validateConfig()` 在保存、应用前继续阻止无效 IPv4 与不连续掩码。`ui_selfcheck` 覆盖空白初始状态、有效静态配置及无效地址拒绝。

## 十、v2.5.2 IPv4 分隔符修正

- 按用户反馈，纯 IPv4 输入框应保留三个句点。将 Qt 输入掩码的空位填充符设为零宽 U+2060，视觉上消除预设空格；覆盖主界面五个字段及附加 IPv4、路径 MTU、局域网主机字段。
- 未填地址统一读为空字符串，短地址和已存配置保持可回填；CIDR、IPv6、主机名输入不加 IPv4 掩码。`ui_selfcheck` 检查显示宽度、空值、回填及相关对话框。

## 十一、v2.5.3 分段宽度与编辑校验

- 零宽填充使句点紧邻，不利于逐段输入。改用不属于空格的 U+2800 留出每段宽度，保留输入掩码及已有空值转换。
- 共用八个纯 IPv4 字段的逐段验证器，输入超过 255 即拒绝；三位自动跳段，一两位按句点跳段。主界面完整值通过 IPv4 解析后再显示有效状态；最终配置校验保留。

## 十二、v2.5.4 输入起点修复

- Qt 掩码允许光标落在空占位位，空字段从中间输入时会产生前导空位与跨段数字。监听光标位置变化，在字段完全为空时重置到首段；有内容时保留自由定位编辑。
- `ui_selfcheck` 复现偏移输入，并覆盖多处光标位置、实际鼠标点击、完整地址插入及已有地址中间修改。
