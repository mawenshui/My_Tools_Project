## 一、文档概述

### 1.1 文档目的

本文档旨在详细描述 NetworkConfigManager 的功能需求和非功能需求，为项目的设计、开发和测试提供依据。文档内容完全基于项目当前源码的实际实现，确保描述的准确性。

### 1.2 产品简介

NetworkConfigManager（IP配置管理器）是一款 Windows 桌面网络配置管理工具，作者 mws，基于 Qt 5.12.12 + C++14 开发。其核心价值在于：为同一块物理网卡保存多套 IP 配置（静态 IP / DHCP），用户可一键快速切换，适用于需要频繁在不同网络环境间切换的工作场景（如运维工程师、现场技术支持人员在办公室网络、客户现场网络、调试网络之间快速切换配置）。

### 1.3 适用读者

- 项目开发人员
- 项目维护人员
- 测试人员
- 产品经理

## 二、项目背景与目标

### 2.1 背景

Windows 操作系统原生提供的网络配置管理界面操作步骤繁琐（需依次进入"控制面板 → 网络和共享中心 → 更改适配器设置 → 属性 → IPv4 属性"），无法保存多套配置以供快速切换。对于需要频繁在不同网络环境间切换的高级用户，缺乏便捷的工具支持。

### 2.2 目标

1. 提供简洁的图形化界面，支持对一块网卡保存多套 IP 配置
2. 支持静态 IP 和 DHCP 两种配置模式
3. 实现最小操作次数的一键配置切换（系统托盘菜单、桌面悬浮球）
4. 保证系统集成的友好性（托盘运行、开机自启、单实例运行）
5. 提供完整的异常处理和日志记录能力，便于问题排查

## 三、功能需求

### 3.1 网络配置管理

| 编号 | 需求名称 | 需求描述 |
|------|----------|----------|
| FR-01 | 新增网络配置 | 用户可为指定网卡新建一条网络配置。配置名称由用户输入，系统自动添加网卡前缀，最终格式为 `[网卡前缀] 配置名称`。支持静态 IP 和 DHCP 两种模式。配置数据持久化保存至 `bin/config/config.json` 文件。 |
| FR-02 | 修改网络配置 | 用户可修改当前选中配置的全部参数。修改后系统自动更新配置内部的网卡前缀以匹配当前选中的网卡，确保配置与网卡始终关联。 |
| FR-03 | 删除网络配置 | 用户可删除当前选中的配置，删除前需二次确认。删除后同步更新 JSON 持久化文件并清空表单。 |
| FR-04 | 应用网络配置 | 用户可将选中配置应用到对应网卡。应用前自动检查网卡管理状态（已禁用则拒绝应用），并对比当前系统配置与目标配置（相同则跳过以提升效率）。应用通过 Windows `netsh` 命令行工具操作。 |
| FR-05 | 配置列表展示 | 主界面以列表形式展示所有已保存的配置。点击列表项可加载该配置的详细信息到表单中查看和编辑。 |
| FR-06 | 静态 IP 配置 | 支持设置 IP 地址、子网掩码、默认网关、首选 DNS、备用 DNS 五个字段。其中 IP 地址和子网掩码为必填项；网关和 DNS 为选填项。若未填写 DNS，应用时系统自动将 DNS 设为 DHCP 获取。 |
| FR-07 | DHCP 配置 | 支持切换为 DHCP 模式（自动获取 IP 地址和 DNS），此时静态 IP 相关输入框自动禁用。 |
| FR-08 | IP 地址格式验证 | 在添加/修改配置以及应用配置时，系统验证 IP 地址、子网掩码、网关、DNS 的格式是否合法（`xxx.xxx.xxx.xxx` 格式，每段 0-255）。 |
| FR-09 | 配置持久化 | 所有配置以 JSON 格式存储，支持结构化的配置读取与写入。每个配置包含 `interface`、`method`、`ip`、`subnet`、`gateway`、`primary_dns`、`secondary_dns` 等字段。 |
| FR-10 | 配置当前状态对比 | 应用配置前，系统通过 `netsh` 命令查询网卡当前 IP/DHCP 状态并与目标配置逐项对比（IP、子网、网关），完全相同则跳过应用并通知用户 "配置未变更"。 |

### 3.2 网卡管理

| 编号 | 需求名称 | 需求描述 |
|------|----------|----------|
| FR-11 | 网卡列表查看 | 系统通过 `netsh interface show interface` 命令获取系统所有网卡列表，在主界面下拉框中显示。同时提供独立网卡管理列表，显示每块网卡的管理状态（已启用/已禁用）和连接状态（已连接/已断开连接）。 |
| FR-12 | 启用网卡 | 用户可通过按钮或托盘/悬浮球菜单对指定网卡执行启用操作。命令执行前检查网卡当前状态（已是启用状态则提示无需操作），执行后自动刷新网卡列表。 |
| FR-13 | 禁用网卡 | 用户可对指定网卡执行禁用操作。与启用逻辑对称，命令执行前检查当前状态避免重复操作。 |
| FR-14 | 刷新网卡列表 | 用户可通过按钮刷新网卡列表，获取最新的网络接口信息。刷新后维持之前的选中状态。 |
| FR-15 | 网卡状态查询 | 系统实时查询每块网卡的管理状态（已启用/已禁用）和连接状态（已连接/已断开连接），并以 `网卡名 [管理状态\|连接状态]` 格式展示。支持中英文状态值的统一转换。 |

### 3.3 快捷切换

| 编号 | 需求名称 | 需求描述 |
|------|----------|----------|
| FR-16 | 托盘快速菜单 | 系统托盘图标的右键菜单中包含"快速应用配置"子菜单。子菜单按网卡分组，每个网卡节点下显示：当前配置信息（灰色不可点击，附打勾标记）、分隔线、该网卡下的所有已保存配置列表。点击配置项直接应用，无需打开主窗口。当前生效的配置项自动打勾标识。 |
| FR-17 | 托盘网卡管理菜单 | 系统托盘右键菜单中包含"网卡管理"子菜单，按网卡分组，每个网卡节点下提供"启用网卡"和"禁用网卡"子项，并显示当前状态。 |
| FR-18 | 托盘其他功能 | 系统托盘右键菜单中包含：显示主窗口、显示/隐藏悬浮球（可勾选）、开机自启动（可勾选）、退出程序。 |
| FR-19 | 桌面悬浮球 | 程序启动后显示一个 64×64 像素的桌面悬浮球窗口，默认置顶显示，背景使用图标（`float_icon.png`）。悬浮球支持鼠标左键拖动到屏幕任意位置，位置自动保存并在下次启动时恢复（含边界检查）。 |
| FR-20 | 悬浮球右键菜单 | 右键点击悬浮球弹出上下文菜单，结构为：按网卡分组的保存配置列表 + 启用/禁用网卡 + "置顶显示"切换 + 分隔线 + "显示主窗口" + "退出"。从悬浮球菜单应用配置前会自动对比当前配置，相同则提示无需重复应用。 |
| FR-21 | 悬浮球交互 | 双击悬浮球显示主窗口。鼠标悬停时指针变为手形。悬浮球始终置顶于其他窗口之上（可通过右键菜单切换）。 |
| FR-22 | 悬浮球视觉 | 悬浮球支持设置背景图片或通过代码绘制圆形彩色背景。默认使用 `float_icon.png` 作为背景图片；配置操作后临时切换为结果指示图标。鼠标悬停时背景颜色变亮 10%。 |

### 3.4 系统集成

| 编号 | 需求名称 | 需求描述 |
|------|----------|----------|
| FR-23 | 单实例运行 | 程序使用 `QSharedMemory` 实现单实例锁（Key 为 `APP_NAME + 进程PID`），防止同时运行多个实例。检测到已有实例时弹出提示对话框并退出。 |
| FR-24 | 开机自启动 | 用户可通过托盘菜单启用/禁用开机自启动。启用时在注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下添加启动项，启动参数为 `--minimized`，开机后程序自动最小化到系统托盘。 |
| FR-25 | 最小化到托盘 | 接收到 `--minimized` 启动参数时，主窗口隐藏，程序在后台运行。关闭主窗口（点击 X 按钮）时，窗口隐藏至系统托盘而非退出程序，需通过托盘菜单"退出"项退出。 |
| FR-26 | 管理员权限检测 | 程序启动后通过 Windows SID API（`AllocateAndInitializeSid` + `CheckTokenMembership`）检测当前进程是否具有管理员权限。无权限时禁用配置操作按钮（应用、添加、修改、删除），状态栏提示 "无管理员权限，部分功能受限"。 |
| FR-27 | 管理员权限提权 | 当需要管理员权限时，使用 `ShellExecuteEx` 以 `runas` 动词重新启动自身进程，请求 UAC 提权。用户取消提权时给予明确提示。 |
| FR-28 | 窗口状态持久化 | 主窗口的几何大小、位置、布局状态通过 `QSettings` 持久化保存和恢复。悬浮窗的位置同理。窗口关闭事件不退出程序，仅隐藏。 |

### 3.6 崩溃处理

| 编号 | 需求名称 | 需求描述 |
|------|----------|----------|
| FR-34 | Windows SEH 异常捕获 | 使用 `SetUnhandledExceptionFilter` 注册全局异常过滤器，捕获 Windows 结构化异常（如访问冲突、除零错误等）。 |
| FR-35 | C++ 异常捕获 | 使用 `std::set_terminate` 注册 C++ 全局终止处理器，捕获 C++ 标准异常、Qt 字符串异常和未知异常。 |

## 四、用户使用场景

### 场景一：办公室网络与客户现场网络快速切换

**WHEN** 运维工程师小王携带笔记本电脑，上午在办公室使用静态 IP `192.168.1.100/24`，下午到达客户现场需要切换为 `10.0.0.50/24` 网段。

**THEN**
1. 小王预先在办公室时通过主界面为"以太网"网卡添加了"办公室"和"客户现场"两个静态 IP 配置。
2. 到达客户现场后，右键点击桌面悬浮球 → 选择"以太网" → 选择"客户现场"配置。
3. 悬浮球图标短暂变色为绿色，状态栏显示"配置应用成功"，气泡弹出通知，3 秒后自动恢复。
4. 网络配置完成，无需打开 Windows 控制面板。

### 场景二：静态 IP 环境与 DHCP 环境切换

**WHEN** 测试工程师小李在办公桌上使用 DHCP 自动获取 IP，但连接调试设备时需要 `192.168.1.200/24` 的静态 IP。

**THEN**
1. 小李为主网卡添加了"调试设备"静态 IP 配置和"DHCP自动"DHCP 配置。
2. 连接调试设备时，右键系统托盘图标 → "快速应用配置" → 选择对应网卡 → 点击"调试设备"。
3. 使用完毕，同样从托盘菜单快速切换回"DHCP自动"配置。
4. 全程无需打开程序主窗口。

### 场景三：禁用不用的虚拟网卡

**WHEN** 用户安装虚拟机软件后产生了多个虚拟网卡，影响日常网络操作，需要临时禁用。

**THEN**
1. 打开 NetworkConfigManager 主界面，在网卡管理区域查看所有网卡及其状态。
2. 找到目标虚拟网卡，若状态为"已启用"，点击"禁用网卡"按钮。
3. 网卡状态变为"已禁用"，按钮状态自动更新（启用变为可用，禁用变为不可用）。
4. 需要时可以随时重新启用。

### 场景四：程序异常崩溃时的问题排查

**WHEN** 用户操作过程中程序发生意外崩溃。

**THEN**
1. 系统捕获到异常（SEH 或 C++ 异常），自动记录错误代码到日志文件。
2. 系统生成 `crash.dmp` 文件到程序目录。
3. 弹出错误对话框："程序发生严重错误，即将退出。错误信息已记录到日志文件。请将 crash.dmp 文件发送给开发者。"
4. 用户将 `crash.dmp` 和对应日期的日志文件发送给开发者，开发者可通过 WinDbg 分析调用堆栈定位问题。

### 场景五：开机自动启动并保持后台运行

**WHEN** 用户希望通过开机自启动让程序在后台静默运行，随时可用。

**THEN**
1. 用户在托盘菜单中勾选"开机自启动"选项。
2. 系统将程序路径（附带 `--minimized` 参数）写入注册表 `Run` 键。
3. 下次开机时，程序自动启动并最小化到系统托盘，不显示主窗口。
4. 用户可通过双击托盘图标或双击悬浮球随时调出主窗口。

## 五、非功能需求

### 5.1 性能需求

| 编号 | 需求描述 |
|------|----------|
| NFR-01 | 配置切换操作（从点击配置项到系统网络生效）应在 3 秒内完成。 |
| NFR-02 | 日志写入操作不应阻塞主线程超过 10 毫秒，日志系统自身通过互斥锁保证写入性能。 |
| NFR-03 | 程序启动（含配置加载和 UI 初始化）应在 2 秒内完成。 |
| NFR-04 | 悬浮球拖动操作应流畅无卡顿，响应延迟不超过 16 毫秒（60fps）。 |
| NFR-05 | `netsh` 命令执行超时设定为 3 秒，超时后返回错误信息而不无限等待。 |

### 5.2 可靠性需求

## 七、v2.2.2 网络工具验收要求

| 功能 | 验收条件 |
|------|----------|
| 备份与回滚 | 应用配置前记录目标网卡当前 IP、网关和 DNS；无法生成或持久化备份时停止修改；可恢复最近备份，含无网关、无 DNS 的静态配置。 |
| 批量配置 | 可勾选多块网卡并批量应用保存配置或 DHCP；重复静态 IP 须提示冲突风险；逐项报告失败并允许回滚。 |
| 网段扫描 | 主页一键按所选网卡实际 IPv4 地址和掩码扫描同网段设备及预设 TCP 端口；仍接受手动输入单个 IPv4、递增区间和 CIDR。最多 2048 个地址、1024 个端口；较大网段提示手动缩小范围。扫描时显示进度条、已完成地址数和发现设备数；展示响应主机与开放端口。 |
| 网络诊断 | 延迟检测优先选择有网关及 DNS 的网卡，保留手动切换；DHCP 自动 DNS 地址应正确读取。支持地区预设与自定义 HTTP(S) 下载测速，提供停止操作；Cloudflare 与 Hetzner 国外预设应能实际接收数据，Hetzner 单路下载；HTTPS 不依赖额外 OpenSSL DLL。 |
| 实时流量与连接 | 主页面展示所选网卡上下行速率；可打开 Windows 网络连接设置。 |
| 主页面 | 上述功能有直接入口，按钮和对话框沿用当前深浅主题。 |

自动化检查使用本地回环网络验证扫描和下载测速，使用隔离配置文件验证配置、历史版本与校验。实际网卡修改及回滚需在管理员权限的隔离测试机验证，避免中断正在使用的网络连接。

## 八、v2.2.3 可选网络参数

静态 IP 配置仅要求 IP 地址与子网掩码。默认网关、DNS 服务器、备用 DNS 服务器均可留空；留空不得触发格式错误，也不得阻止保存或恢复无对应地址的备份。无 DNS 时清空静态 DNS 列表；仅填写备用 DNS 时，将该地址作为唯一 DNS 使用。

## 九、v2.3.0 主界面视觉

默认浅色主题；主页面网络工具入口分为两行，流量状态独立显示。窗口至少 980×690，IP 表单标签完整可读。主窗口、对话框和常用控件使用柔和渐变与深色文字，焦点及选中状态需清晰；托盘菜单保留暗色主题切换。
