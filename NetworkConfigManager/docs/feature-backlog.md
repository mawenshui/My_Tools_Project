# NetworkConfigManager 离线网络工具箱扩展清单

调研日期：2026-10-12。目标：Windows 本地网卡配置、局域网排障与网络测量工具箱。所有核心功能在断网时可启动、查看本机数据并完成本地计算；主动探测只访问用户指定的目标或本地网络，不以账号、云服务、公共测速站、在线数据库为前提。本文借鉴功能思路，不复制第三方代码。

## 当前基线与范围

项目已有：IPv4 静态/DHCP 配置与预设、启停网卡、托盘快捷切换、配置历史、应用前备份及回滚、批量配置、IPv4 网段/TCP 端口扫描、延迟丢包检测、HTTP(S) 下载测速、实时流量、日志导出。以下清单主要补齐这些功能的安全性、可观察性与局域网工具能力；“增强”表示在现有入口上扩展，不另造重复工具。

优先级：**P0** 先保证配置可靠与数据可恢复；**P1** 补常用诊断；**P2** 加专业功能。每项独立可交付，编号用于后续需求和测试追踪。参考项目代号见文末；“借鉴”仅说明需求来源，本项目的实现与验收以本表为准。

### P0 实现记录（2026-10-12）

- C01：新建和更新预设保存网卡 GUID；读取旧配置时按真实友好名迁移。已绑定网卡改名后仍按 GUID 定位，离线时停止应用。旧配置名称无法唯一匹配时，主窗口应用前要求手动选择。
- C02：主窗口、托盘快捷应用和批量应用前显示当前与目标字段；区分未设置与设为空，并提示静态 IP 重复、网关跨子网及连接中断风险。
- C03：备份以 `QSaveFile` 提交成功后逐步执行地址和 DNS 命令，显示步骤、退出码与错误；完成后重读系统配置并列出未生效字段。自动测试覆盖命令失败与网卡标识失效。
- C04：回滚按钮可按时间、网卡和地址摘要选择任一快照，恢复前再次备份。应用前可勾选 60 秒确认期限，未确认时恢复上一快照；该待确认状态仅存在于当前进程，重启不会执行过期恢复。
- C05：导出版本 1 JSON，默认不含 GUID；导入兼容旧 JSON，先预览有效项、同名项和无效项，再选择跳过、改名或覆盖。文件写入使用临时文件提交。
- C06：只读及配置文件管理允许普通用户使用，修改网卡时才请求管理员重启。网卡名称、GUID 和 DNS 地址在执行前验证；系统命令使用参数列表，日志记录步骤与退出码。

配置写入类操作仍需在隔离管理员测试机执行真实网卡验收；自动测试不修改当前网络连接。

## P1：网卡、地址与路由

| ID | 功能 | 具体行为与验收 | 借鉴 |
| --- | --- | --- | --- |
| N01 | 网卡详情页增强 | 展示 GUID、MAC、链路速率、IPv4/IPv6、DHCP 状态、DNS、网关、MTU、接口跃点数、驱动信息和收发计数；标注字段来源与刷新时间。断开连接的网卡仍可查看已知配置。 | [S3], [S4] |
| N02 | IPv6 查看与配置 | 先做只读展示，再支持静态 IPv6、前缀、网关和 DNS；区分 SLAAC/DHCPv6/静态，避免用 IPv4 模式推断 IPv6。应用前后分别备份与验证两个地址族。 | [S3] |
| N03 | 多 IPv4 地址 | 同一网卡管理主地址与附加地址；新增/删除附加地址不覆盖主地址，配置预览给出精确差异。备份能完整恢复地址列表。 | [S3] |
| N04 | 路由表查看与管理 | 按 IPv4/IPv6、网卡、目标网段过滤；显示网关、跃点数、持久性和来源。新增/删除静态路由前预览，禁止误删系统动态路由，操作可回滚。 | [S3], [S4] |
| N05 | DNS 设置与缓存工具 | 查看每块网卡 DNS 顺序、自动/手动状态；提供本机 DNS 缓存查看与清空。清缓存单独确认，不和改 IP 绑定。 | [S4] |
| N06 | MTU 与接口跃点数 | 展示当前值和系统允许范围；修改前保存旧值并验证生效。提供恢复默认按钮，不通过猜测自动改动。 | [S4] |
| N07 | Wi-Fi 状态与环境 | 本地显示 SSID、BSSID、信号强度、频段、信道、速率与认证方式；扫描附近接入点并按信道聚合，提示系统权限或无线网卡缺失。无云端信道评分。 | [S3], [S4] |

### v2.4.0 实现记录（2026-10-12）

- N01–N02：新增“网卡、地址与路由”页，从本机 NetAdapter、NetTCPIP、DnsClient 读取 GUID、链路、驱动、收发计数和 IPv4/IPv6 状态；显示数据来源与刷新时间。IPv6 按 DHCPv6、路由发现和每条地址来源分别展示。新增静态 IPv6 时可指定前缀、网关及 DNS。
- N03–N04：附加 IPv4 使用 `SkipAsSource`，删除时拒绝主地址和自动地址；路由按地址族、网卡、网段、来源过滤，只允许删除 `NetMgmt` 静态路由。新增与删除均复读系统结果。
- N05–N07：查看每块网卡 DNS 顺序与设置来源；DNS 缓存查看、清空单独操作。MTU 与接口跃点支持修改和恢复保存的原值，不猜测设备默认 MTU。Wi-Fi 使用本机 WLAN 信息并按信道统计 BSSID。
- 修改前读取并原子保存双栈地址、路由、DNS、MTU 快照到本机 `config/network_tool_backups.json`；执行后复读，并提示其他地址族的变化。取消与 30 秒超时可终止当前系统进程。高级网卡管理依赖 Windows NetTCPIP PowerShell 模块；模块不可用时仍显示 IP Helper 基础信息，原有配置切换入口继续可用。真实修改及恢复需在隔离管理员测试机验收。

## P1：诊断、局域网发现与报告

| ID | 功能 | 具体行为与验收 | 借鉴 |
| --- | --- | --- | --- |
| D01 | 连续 Ping 增强 | 用户选择网卡和目标；展示逐次 RTT、丢包、最小/平均/最大值、抖动趋势及时间轴。可暂停、停止和导出；目标不可达与超时分开统计。 | [S5], [S6] |
| D02 | 路由追踪 / MTR 视图 | 对指定 IPv4/IPv6 目标按跳显示 RTT、超时、丢包；连续模式记录变化。中间路由器不回应时仍继续探测；设最大跳数与超时。 | [S3], [S7] |
| D03 | DNS 查询台 | 指定系统 DNS 或用户输入的解析器，查询 A/AAAA/CNAME/MX/NS/TXT/PTR；展示响应、TTL、耗时、错误及原始服务器。仅在用户执行查询时访问指定服务器。 | [S3], [S5] |
| D04 | 端口与服务检查 | 对单个主机或受限局域网范围检测 TCP 连接、常见端口预设和自定义列表；给出开放/拒绝/超时及耗时。沿用现有扫描器，增加可取消和结果过滤。 | [S4], [S5] |
| D05 | 网段扫描增强 | 将已有 TCP 扫描与本地 ARP/邻居表、ICMP 结合，逐项注明发现来源；显示 MAC、反向 DNS、首次/最近发现时间。设置并发、速率、范围上限，停止后保留部分结果。 | [S1], [S5] |
| D06 | 子网计算器 | 纯本地计算 IPv4/IPv6 CIDR、掩码、网络地址、广播地址、可用主机范围和数量；正确处理 IPv4 /31、/32 与 IPv6 /128，支持把结果填入扫描范围。 | [S5] |
| D07 | 路径 MTU 探测 | 指定目标，逐步寻找最大不分片载荷；展示每次探测、估计 MTU 和“不确定”结果。遇到 ICMP 被过滤时提示限制，不把超时当作确定 MTU。 | [S4] |
| D08 | 本地健康检查 | 按“网卡链路→地址/网关→网关可达→指定 DNS→用户指定目标”逐项诊断，记录耗时和证据。断网时前两项仍可运行；不默认探测公共网站。 | [S4] |
| D09 | LAN 吞吐测试 | 可选两台本地机器一端监听一端连接，测吞吐与重传/丢包；端口、测试时长、数据量可控。无公网测速服务器依赖，安装第三方组件前核对许可。 | [S4] |
| D10 | HTTP(S) 目标诊断 | 对用户输入的内网或外网 URL 显示 DNS、连接、TLS、首字节、状态码、重定向和证书摘要；不下载大文件。沿用现有网络诊断入口，与下载测速分开。 | [S4] |
| D11 | 本地报告与时间对比 | 将选定网卡快照、路由、DNS、探测和扫描结果导出 TXT/CSV/JSON；预览并可遮盖 IP、MAC、SSID、主机名。历史仅存本机，按时间比较两次快照。 | [S4], [S5] |

### v2.5.0 实现记录（2026-10-13）

- D01–D03：新增连续 Ping（网卡源地址、逐次时间、RTT、丢包、不可达、抖动、暂停/停止/TXT）、按跳路由追踪（IPv4/IPv6、跳数/超时、连续模式）和系统/指定解析器 DNS 查询（A/AAAA/CNAME/MX/NS/TXT/PTR、TTL、耗时）。
- D04–D06：沿用原扫描器，增加端口预设、开放/拒绝/超时与耗时、ICMP/TCP/ARP 来源、反查主机名、首次/最近发现时间、并发/全局间隔/过滤与停止后的部分结果。扫描限制 2048 地址、1024 端口。IPv4/IPv6 子网计算器处理 /31、/32、/128；可将小范围 IPv4 填入扫描器。
- D07–D10：逐步 DF 探测 IPv4 路径 MTU，超时不推断确定值；本地健康检查先记录链路、地址、网关，再按需探测网关、当前 DNS 和用户目标。双机 UDP 工具限制局域网目标、时长和数据量，测吞吐及缺号；缺号不能区分丢包和乱序，也不提供 TCP 重传计数。HTTP(S) 诊断仅向用户 URL 发 HEAD，请求结果含 DNS、连接、TLS、首字节、状态、重定向与证书摘要。
- D11：本机报告包含网卡双栈快照、路由、DNS、探测与最近扫描；预览、可选隐私遮盖、TXT/CSV/JSON 导出，历史保留最多 50 份并可比较两次网卡快照。报告数据只保存在本机 `config/`。
- 主动探测只在用户启动后执行。原延迟检测移除了默认公网 DNS 目标；原下载测速作为独立旧功能保留。真实双机 LAN、不同 DNS 环境、IPv6 追踪及受限 ICMP 路径仍需对应网络环境验收。

## P2：专业场景

| ID | 功能 | 具体行为与验收 | 借鉴 |
| --- | --- | --- | --- |
| X01 | 局域网设备变更提醒 | 仅对用户保存的本地网段定时扫描；新增/消失设备用本机通知，保留发现方式和时间。默认关闭，间隔与并发可设，退出后不运行。 | [S1] |
| X02 | 协议端口提示 | 基于用户维护的本地端口映射，为扫描结果提示常见服务（如 SSH、RDP、Modbus/TCP、S7、RTSP）；明确写“推测”，不自动登录或发送控制指令。 | [S1] |

## 通用验收约束

- **离线性**：拔掉外网后，启动、配置切换、本地计算、网卡信息、历史、导入导出照常可用。主动探测只访问用户指定目标或明确选定的本地网段；无账号、遥测、自动更新、公共 API、公共测速站依赖。
- **安全性**：改配置前完成可恢复备份；对网卡身份、IP/CIDR、端口、URL 和命令参数做边界校验。扫描与测速有范围、并发、时长和取消控制。网卡管理操作提供结果复核。
- **权限与可用性**：只读功能普通用户可用；需要管理员或驱动的功能单独提示。所有耗时任务离开 UI 线程；断网、禁用网卡和目标无响应时仍可取消。
- **数据**：历史与报告只保存在本机，敏感字段导出时可遮盖；文件写入用临时文件提交，避免崩溃产生半份配置。
